## 2026-04-30: Phase 1~8 1차 구현 (autopilot)

### 변경 내용
1차 버전의 코드 골격을 한 번에 구현. `04_개발_계획.md`의 Phase 1~8을 따름.

#### Phase 1 — 프로젝트 골격
- `build.gradle.kts`(루트), `settings.gradle.kts`, `gradle.properties`, `gradle/wrapper/*` (Muffle 기준 동일 환경)
- `app/build.gradle.kts`: AGP 8.2.2 / Kotlin 1.9.22 / Compose Compiler 1.5.8 / kapt(Room) / `com.sinced` namespace
- `AndroidManifest.xml`: `SincedApplication` + `MainActivity` (LAUNCHER intent), 권한 없음 (1차는 알림 미포함)
- `res/values/strings.xml` (앱명 "Sinced"), `themes.xml`(NoActionBar), 적응형 런처 아이콘 (placeholder)
- `.gitignore` 작성 (Android 표준 + `.omc/state/`)

#### Phase 2 — 데이터 계층
- 엔티티: `Category`, `Item`, `LogEntry` (FK SET_NULL/CASCADE, 인덱스 포함)
- DAO: `CategoryDao`, `ItemDao`, `LogEntryDao` — Flow 기반 observe 쿼리
- 관계 데이터: `ItemWithLastLog` (메인 리스트용 조인 결과 holder)
- `SincedDatabase` (version=1) + 싱글톤 `getInstance`
- Repository: `CategoryRepository`, `ItemRepository`, `LogRepository`
- 시드: `DefaultCategories.seedIfEmpty(dao)` — 첫 실행 시 4종 카테고리 + 팔레트 색상 부여

#### Phase 3 — 도메인 로직
- `domain/model/`: `ItemStatus` enum, `ItemView` data class
- `domain/util/DateUtil`: epoch millis ↔ LocalDate, `daysBetween`(자정 기준), `addDays`, `formatDate("yyyy-MM-dd")`
- `domain/util/ItemDeriver`: `daysSince` / `nextDueAt` / `daysUntilDue` / `status` 계산. status 평가 순서는 `02_데이터_모델.md` 그대로 (NEVER_LOGGED → TRACKING_ONLY → OVERDUE → DUE_TODAY → DUE_SOON → OK)
- `domain/util/ItemFormatting`: 배지 표기 규칙(`D-N`/`D-DAY`/`D+N`/`N일 경과`/`기록 없음`)
- `domain/filter/ItemFilters`: `CycleFilter`, `SortOption`, `FilterState` + sort/filter 적용 함수
- `prefs/UserPreferences`: SharedPreferences (`sinced_prefs`)에 `cycle_filter`/`sort_option`/`category_filter` 저장. 미분류는 `__uncategorized__` 키로 인코딩

#### Phase 4 — 메인 화면
- `MainScreen` + `MainViewModel` (combine: items + categories + filter → derived ItemView 리스트)
- 컴포넌트: `FilterBar`(전체/D-day/경과일 + 카테고리 드롭다운), `SortMenu`, `ItemCard`(상태별 배지 색상)
- 빠른 기록: 항목 카드 **롱프레스** → 오늘 날짜로 LogEntry 추가 (스와이프는 1차에서 제외, FilterChip + 롱프레스로 대체)
- 빈 상태 분기: 항목 0개 vs 필터 결과 0개

#### Phase 5 — 항목 추가/편집
- `ItemEditScreen` + `ItemEditViewModel` (신규/편집 공용)
- 카테고리 칩 (미분류 포함), 주기 토글 + 숫자 입력, 메모, "첫 기록도 함께 등록" 옵션 (DatePicker, 미래 날짜 차단)
- 입력 검증: 이름 필수, 주기는 1 이상 정수

#### Phase 6 — 항목 상세 / 이력
- `ItemDetailScreen` + `ItemDetailViewModel` (item / logs / categories combine)
- 상태 요약(D-day, 마지막 기록, 다음 예정, 주기, 카테고리, 메모)
- 이력 LazyColumn — `LogRow`: 탭 → 편집 다이얼로그 / 롱프레스 → 삭제 확인
- 우상단 메뉴: 보관 / 영구삭제 (삭제 시 "이력 N건이 함께 삭제됩니다" 확인)
- 기록 추가/편집: `LogEntryDialog` (오늘/어제/그저께 칩, DatePicker, 미래 차단)

#### Phase 7 — 카테고리 관리
- `CategoryManageScreen` + `CategoryViewModel`
- 추가 / 이름변경 / 색상 변경(8색 프리셋 + "색상 없음") / 위·아래 화살표로 순서 변경 / 삭제(영향 항목 수 안내)
  - 드래그 정렬은 후순위 — 1차는 화살표 버튼으로 단순 처리

#### Phase 8 — 마무리
- 다크 테마 고정: `SincedTheme` (`darkColorScheme`), 상태 색상(`StatusOverdue/DueToday/DueSoon/Ok/NeverLogged`) + `CategoryPalette` 8색

- `SincedViewModelFactory` (DI 프레임워크 미사용 — Application이 Repository 보유)
