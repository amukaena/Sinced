## 2. 환경 변수 설정 (최초 1회)

> ⚠ 이미 한 번 설정한 PC라면 다시 실행하지 말 것. 아래 스크립트는 **PATH에 중복 추가**될 수 있으므로 멱등성 가드를 두었음.

**PowerShell (관리자 권한)에서 실행:**

```powershell
# JAVA_HOME 설정 (이미 같은 값이면 변화 없음)
[Environment]::SetEnvironmentVariable("JAVA_HOME", "D:\00_JDK\jdk-17", "User")

# ANDROID_HOME 설정
[Environment]::SetEnvironmentVariable("ANDROID_HOME", "D:\Android", "User")

# Path에 추가 (이미 포함된 경로는 스킵 — 중복 누적 방지)
$currentPath = [Environment]::GetEnvironmentVariable("Path", "User")
$pathsToAdd = @(
    "D:\00_JDK\jdk-17\bin",
    "D:\Android\cmdline-tools\latest\bin",
    "D:\Android\platform-tools"
)
$existing = $currentPath -split ';'
$missing = $pathsToAdd | Where-Object { $existing -notcontains $_ }
if ($missing.Count -gt 0) {
    $newPath = ($existing + $missing | Where-Object { $_ }) -join ';'
    [Environment]::SetEnvironmentVariable("Path", $newPath, "User")
    Write-Host "추가됨: $($missing -join ', ')"
} else {
    Write-Host "PATH 변경 없음 (이미 모두 포함됨)"
}
```

**설정 후 VSCode/터미널 재시작 필요**

## 4. 기기 연결 (USB 디버깅)

1. **개발자 옵션 활성화**: 설정 > 휴대전화 정보 > 빌드 번호 7번 탭
2. **USB 디버깅 켜기**: 설정 > 개발자 옵션 > USB 디버깅 ON
3. **연결 확인**: `adb devices`

## 5. 빌드 & 실행

프로젝트 루트에서:

```powershell
# 빌드
./gradlew assembleDebug

# APK 설치 & 실행
./gradlew installDebug

# 또는 직접 설치
adb install app/build/outputs/apk/debug/app-debug.apk
```
