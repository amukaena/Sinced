# Sinced - 화면 설계

## 화면 목록

| # | 화면 | 역할 |
|---|------|------|
| 1 | 메인 (항목 리스트) | 모든 항목을 한 화면에 표시, 필터/정렬, 빠른 기록 |
| 2 | 항목 추가/편집 | 이름, 카테고리, 주기, 메모 입력 |
| 3 | 항목 상세 / 이력 | 해당 항목의 LogEntry 누적 보기, 추가/수정/삭제 |
| 4 | 행위 기록 (다이얼로그) | 날짜(기본 오늘, 소급 가능) + 메모 |
| 5 | 카테고리 관리 | 카테고리 추가/이름변경/색상/순서/삭제 |
| 6 | 설정 (최소) | 앱 정보, 향후 확장 |

Navigation Compose로 라우팅. 4번은 다이얼로그로 처리.

## D-day / 경과일 표기 규칙 (전 화면 공통)

| 상태 | 표기 예 | 비고 |
|------|---------|------|
| 다음 예정일까지 N일 남음 (N>0) | `D-N` | 양수 = "남음" |
| 오늘이 예정일 | `D-DAY` | |
| 예정일 지남 (N일 초과) | `D+N` | 음수가 아니라 `+`로 표기 |
| `cycleDays == null` | `N일 경과` | 경과일만 표시 |
| LogEntry 0건 | `기록 없음` | 회색 |

> "D-2 (지남)" 같은 혼용 표기는 사용하지 않음. 지났으면 `D+2`.

## 1. 메인 화면 (항목 리스트)

```
┌──────────────────────────────────────┐
│ Sinced                       ⚙ │  ← 상단 앱바 (설정 진입)
├──────────────────────────────────────┤
│ [전체] [D-day] [경과일] [카테고리▾]  │  ← 필터 칩 (가로 스크롤)
│ 정렬: 임박순 ▾                       │  ← 정렬 드롭다운
├──────────────────────────────────────┤
│   샤워기 필터              D-2       │  ← 임박(DUE_SOON), 노랑 계열 강조
│   교체/소모품 · 60일 주기            │
│   마지막: 58일 전 (2026-03-03)       │
├──────────────────────────────────────┤
│   게임 정액제             D-12       │
│   구독 · 30일 주기                   │
│   마지막: 18일 전                    │
├──────────────────────────────────────┤
│   로봇청소기 먼지통       12일 경과  │  ← cycleDays=null
│   청소                               │
├──────────────────────────────────────┤
│   체중 측정              기록 없음   │  ← NEVER_LOGGED
│   건강                               │
└──────────────────────────────────────┘
                                ┌───┐
                                │ + │  ← FAB: 항목 추가
                                └───┘
```

### 항목 카드 동작
- **탭**: 항목 상세(이력) 진입
- **롱프레스**: "지금 기록" 빠른 액션 (오늘 날짜로 LogEntry 추가)
- **우측 스와이프**: 빠른 기록
- **좌측 스와이프**: 보관(archive) — 삭제 아님, 복원 가능

### 필터 칩
- `전체` / `D-day 있음` / `D-day 없음` (= cycleDays null)
- `카테고리▾`: 카테고리 다중 선택 가능. 항목의 `categoryId == null`인 경우는 **"미분류"**라는 가상 옵션으로 노출
- 체크된 필터는 강조 표시, 다시 탭하면 해제

### 정렬 옵션
| 옵션 | 정렬 키 | NEVER_LOGGED 처리 |
|------|---------|-------------------|
| 임박순 | `daysUntilDue` 오름차순 (D-day 없는 항목은 뒤로) | 맨 뒤 |
| 오래된 순 | `daysSince` 내림차순 | 맨 위 (한 번도 안 한 = 가장 오래됨) |
| 이름 | `name` 가나다순 | 자연 정렬 |
| 직접 정렬 | `Item.sortOrder` | 자연 정렬 |

선택한 정렬은 SharedPreferences에 저장(앱 재시작 시 유지).

## 2. 항목 추가/편집 화면

```
┌──────────────────────────────────────┐
│ ← 항목 추가                   저장  │
├──────────────────────────────────────┤
│ 이름                                 │
│ ┌──────────────────────────────────┐ │
│ │ 샤워기 필터                       │ │
│ └──────────────────────────────────┘ │
│                                      │
│ 카테고리                             │
│ [청소] [구독] [교체/소모품]✓ [+ 추가]│
│                                      │
│ ☐ 주기 설정 (D-day 표시)             │
│   ▼ 체크 시 노출                     │
│   주기: [ 60 ] 일                    │
│                                      │
│ 메모 (선택)                          │
│ ┌──────────────────────────────────┐ │
│ │                                   │ │
│ └──────────────────────────────────┘ │
│                                      │
│ ─────────────────────────────────── │
│ ☐ 첫 기록도 함께 등록                │
│   ▼ 체크 시 노출                     │
│   날짜: [ 2026-03-03 ] 📅            │
│   메모: [                       ]    │
└──────────────────────────────────────┘
```

- "주기 설정" 체크박스로 D-day 추적 여부 결정
- "첫 기록도 함께 등록" — 신규 항목 추가 시 LogEntry를 같이 만드는 편의 옵션 (소급 입력 케이스에 핵심)

## 3. 항목 상세 / 이력

```
┌──────────────────────────────────────┐
│ ← 샤워기 필터              ✏ ⋮     │  ← 편집/메뉴(보관·삭제)
├──────────────────────────────────────┤
│ D-2                                  │  ← 5월 2일까지 2일 남음 (DUE_SOON)
│ 마지막 기록: 2026-03-03 (58일 전)    │
│ 다음 예정: 2026-05-02                │
│ 주기: 60일                           │
├──────────────────────────────────────┤
│ 이력 (3건)                           │
│                                      │
│ 2026-03-03   필터 새 거 1번         │
│ 2026-01-02   - (메모 없음)           │
│ 2025-11-04   - (메모 없음)           │
│                                      │
│                          ┌─────────┐ │
│                          │ + 기록  │ │
│                          └─────────┘ │
└──────────────────────────────────────┘
```

- 이력 행 **탭** → 수정 다이얼로그
- 이력 행 **롱프레스** → 삭제 확인
- 우상단 ⋮ → 보관 / 영구삭제
  - **영구삭제** 선택 시 다이얼로그:
    - 제목: "항목을 삭제할까요?"
    - 본문: "이력 N건이 함께 삭제됩니다. 되돌릴 수 없습니다."
    - 버튼: `[ 취소 ]` / `[ 삭제 ]` (삭제 버튼은 빨강)
    - 확인 시 `Item` + 관련 `LogEntry`가 ON DELETE CASCADE로 함께 제거됨

## 4. 행위 기록 다이얼로그

```
┌──────────────────────────────────────┐
│ 기록 추가                            │
├──────────────────────────────────────┤
│ 날짜: [ 2026-04-30 ] 📅              │  ← 기본 오늘, 탭하여 변경
│       [오늘] [어제] [그저께]         │  ← 빠른 선택 칩
│                                      │
│ 메모 (선택)                          │
│ ┌──────────────────────────────────┐ │
│ │                                   │ │
│ └──────────────────────────────────┘ │
│                                      │
│           [ 취소 ]   [ 저장 ]        │
└──────────────────────────────────────┘
```

- DatePicker 사용
- 미래 날짜 입력 차단 (오늘까지만 허용 — **기기 로컬 타임존 기준**)
- **같은 날 중복 입력 허용**: 동일 항목에 같은 날짜로 LogEntry를 여러 건 만들 수 있음 (병합/차단 안 함)
  - 빠른 기록(롱프레스/스와이프)도 동일 — 누를 때마다 새 LogEntry 생성
  - 의도: 하루에 여러 번 한 행위(예: 청소 오전/오후)를 그대로 기록할 수 있게
  - `daysSince` / `daysUntilDue` 계산은 어차피 `MAX(performedAt)`만 보므로 중복이 있어도 결과 영향 없음

## 5. 카테고리 관리

```
┌──────────────────────────────────────┐
│ ← 카테고리 관리                      │
├──────────────────────────────────────┤
│ ☰ 청소                          ✏ ✕ │
│ ☰ 구독                          ✏ ✕ │
│ ☰ 교체/소모품                   ✏ ✕ │
│ ☰ 건강                          ✏ ✕ │
│                                      │
│              [ + 카테고리 추가 ]     │
└──────────────────────────────────────┘
```

- ☰ 드래그로 순서 변경
- 삭제 시 "이 카테고리의 항목 N개는 '미분류'가 됩니다" 확인 다이얼로그

## 테마
- **다크 테마 고정** (1차 버전) — 시스템 라이트 모드여도 다크로 표시
  - `MaterialTheme(colorScheme = darkColorScheme(...))`로 강제
  - 라이트 테마 / 시스템 따름은 후순위
- 강조색: 차분한 톤 (구현 시점에 darkColorScheme 기반으로 확정)
- 상태 색상 (다크 배경 위에서 가독성 고려):
  - OVERDUE: 빨강 계열
  - DUE_TODAY: 주황 계열
  - DUE_SOON (≤3일): 노랑 계열
  - OK: 기본 텍스트 색 (`onSurface`)
  - NEVER_LOGGED: 회색 (`onSurfaceVariant`)

## 빈 상태
- 항목 0개: "첫 항목을 추가해보세요" 안내 + FAB 강조
- 필터 결과 0개: "조건에 맞는 항목이 없습니다"
