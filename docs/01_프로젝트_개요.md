# Sinced - 프로젝트 개요

## 앱 소개
"마지막 행위로부터 며칠 지났는지" 또는 "다음 주기까지 며칠 남았는지"를 추적하는 Android 앱.

- **경과일 추적**: 로봇 청소기 먼지통 비움, 샤워기 필터 교체 등 — 마지막 기록 이후 며칠 지났는지 확인
- **주기 D-day 추적**: 게임 정액제, 구독 상품 등 — 다음 갱신/교체일까지 며칠 남았는지 확인

하나의 항목에 **주기(일)** 필드를 옵션으로 둬서, 주기 값이 있으면 D-day, 없으면 경과일만 표시.

## 핵심 기능
| 기능 | 설명 |
|------|------|
| 항목 등록 | 이름, 카테고리, 주기(옵션), 메모 |
| 행위 기록 | 항목에 "오늘 했음" 또는 과거 날짜 소급 입력 |
| 이력 누적 | 항목당 다회 기록 저장, 히스토리 조회 |
| 경과일 / D-day 표시 | 주기 유무에 따라 자동 분기 |
| 필터링 | D-day 있는 것만 / 없는 것만 / 카테고리별 |
| 정렬 | 임박순(D-day) / 오래된 순(경과일) / 이름 / 직접 정렬 |
| 카테고리 관리 | 사용자 정의 카테고리 |

> **알림 기능 없음** (1차 버전). 앱 진입 시 화면에서만 확인.
> **백업/동기화 없음** (1차 버전). 차후 확장.

## 기술 스택
| 항목 | 선택 |
|------|------|
| 언어 | Kotlin |
| UI | Jetpack Compose + Material3 |
| 최소 SDK | 26 (Android 8.0) |
| 타겟 SDK | 34 (Android 14) — FitLog/Muffle과 동일. SDK 36까지 설치돼 있어도 빌드는 34로 고정 |
| 아키텍처 | MVVM |
| 영속성 | Room (이력 누적 저장) |
| 비동기 | Kotlin Coroutines + Flow |
| 빌드 | Gradle (Kotlin DSL) |
| 패키지 | `com.sinced` |

## 설계 원칙
- **단순성 우선**: 알림/동기화는 후순위. 1차는 "잘 보여주고 잘 기록하는" 데 집중
- **소급 입력 친화**: 과거 시점 기록을 자연스럽게 받을 수 있는 UX (이미 사용 중인 항목을 뒤늦게 등록하는 케이스 흔함)
- **이력 보존**: 한 번 기록한 행위는 수정/삭제 가능하되 기본은 누적
